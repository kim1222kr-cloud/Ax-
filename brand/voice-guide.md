> 근거: 필름 대표작 제목·책 소개 문구·@feelmbook 확인 포맷 분석(docs/research/feelm-research-report.md §5). brand-editor가 채점 기준으로, copy-director가 작성 기준으로 쓴다. 개정은 리드가 `_planning/registry-proposals.md` 제안을 검토해 직접 반영한다.

## 0. 한 문장
**"우리의 이야기는 영화다."** — 누군가의 삶에서 영화 같은 한순간을 꺼내, 위로와 확신으로 건넨다. 결핍을 풍요로.

## 1. 공통 원칙
| 지킨다 | 피한다 |
|---|---|
| 2인칭 존댓말 구어체("~해도 괜찮아요", "당신은 결국 ~사람") | 반말 명령형, 설교조 |
| 문장형 제목 — 질문형 / 2인칭 확언형 | 명사 나열형 제목("자존감 회복 5단계 총정리") |
| 짧은 줄, 한 장 한 메시지 | 한 장에 세 가지 이상 메시지 |
| 저자 본인이 말한 시련 → 회복 | 지어낸 사연, 일반인 화자, 마지막 장 반전형 광고 |
| 사실 기반 전작 연결, 등록 수치+시점 | 미등록 수치, "국민 ~", 숫자 없는 "베스트셀러" |
| 출판사 콘텐츠임을 처음부터 드러냄 | "광고 아님", "내돈내산" |
| 담백한 감탄 | 충격·경악·소름·역대급·미쳤다·실화냐 |

## 2. 트랙별
### essay — 감성 에세이 · 문장카드
- 톤: 위로·자존감·자기확신. 따뜻하지만 단단하게.
- 좋은 예: "헤맨 시간도 **전부 내 땅**이 된다" / "요즘 길을 잃은 것 같다면" / "당신은 결국 해내는 사람이에요"
- 나쁜 예: "자존감 바닥인 사람 특징 5가지" (낙인형) / "이 책 안 읽으면 손해" (압박형)

### money — 재테크 · 경제경영 정보형
- 톤: 담백한 정보·실행. 숫자는 기간·항목 수로. 개인 사례임을 밝힌다.
- 좋은 예: "종잣돈, 어디서부터?" / "월 200 받던 간호사 부토리의 첫 1년" / "오늘 점검할 5가지"
- 나쁜 예: "4년 만에 27억, 당신도 가능" (일반화) / "무조건 오르는 ETF" (수익 보장)
- 필수 고지: "저자의 개인 사례이며 수익을 보장하지 않습니다."

### insight — 해외 번역서 인사이트
- 톤: 저자 권위(공식 경력 사실) + 3줄 원칙, 지적·간결.
- 좋은 예: "전 골드만삭스 CEO가 말하는 생존 지능" / "핵심은 이 세 가지"
- 나쁜 예: "세계 최고의 CEO가 극찬" (출처 없는 과장) / 원문 장문 인용 (원권리사 범위 확인 전)

## 3. 숏폼 기본기
1. 0~3초: 질문 또는 의외의 사실, 20자 안팎, 큰 자막
2. 소리 없이도 이해되는 자막(안전영역: 상단 220px·하단 420px 회피)
3. 장면당 메시지 하나, 2.5~3.5초
4. 마지막: 저장·DM 공유 동기("이 문장이 필요한 친구에게")
5. 쇼츠 CTA 핸들은 "필름 출판사"

## 4. 고정 표기
- 출판사: 필름 / 필름출판사 / (주)필름 — '필림'·'Film' 금지, 영문은 FEELM
- 대표: "작가 김상현" (동명이인 방지)
- 크리에이터: "창업오빠 강호동", "로사장(김다솔)" 1인, "희철리즘"
- 도서명: 『』, 영상 제목에서는 《》 허용
- 해시태그: #필름출판사 + 도서명 고정, 총 5개 이하
