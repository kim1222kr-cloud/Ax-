# 필름 콘텐츠 포맷 라이브러리 (F01–F12)

> 기획은 "포맷 선택 + 변수 채우기"다. copy-director는 `templates/cardnews/<F>.json`, `templates/shortform/<F>.json`을 복제해 `{{…}}` 자리를 채운다.
> 모든 포맷 공통: 사연·일반인 위장 금지 · 광고 표기 첫 줄 · 수치는 `data/claims.json` 등록분만 · 인용은 `assets/quotes.json` 원문만 · 대표 서사는 grant(ceo_story) 후에만 · 해시태그 5개 이하 · 캐러셀 2~10장(API 한도) · 4:5(1080×1350).

## F01 문장 처방 카드
- **구조(캐러셀)**: cover(kicker=상황 질문 "요즘 길을 잃은 것 같다면", title=2인칭 확언 2줄) → text(공감 상황 2~4줄) → quote(quotes.json 승인 문장+page. 없으면 책 제목 문장 + "— 책 제목에 담긴 문장") → text(2인칭 해석) → stat(등록 수치만, 없으면 삭제) → book → cta("저장해두고 다시 읽기", "이 문장이 필요한 친구에게 보내기")
- **숏폼**: hook(≤2.6초) → caption ×2 → quote → book → cta(handle "필름 출판사")
- **대상**: 김상현 4종(대표 서사 제외), 희철리즘, 이해인, 원의독백
- **왜**: 필름의 가장 강한 문장 IP + 질문형·확언형 제목 DNA. 저장·DM 공유형. 훅 실험(질문형 vs 확언형)의 기본 실험대.

## F02 필름이 고른 MBTI 책 처방 (시리즈)
- **구조**: 대표 도서 1권만 `--book`, 나머지는 campaign.json `featured_books[]`. cover("ISTJ에게 필름 직원이 고른 책" — 직원 선정 기록 `assets/mbti-selection.*`이 있을 때만. 없으면 "필름이 펴낸 책 중 ISTJ에게") → text(유형 특징 3줄, "~한 편이라면" 완곡형) → book ×1~4 → list("이런 날 펼쳐보세요" 3) → cta("친구 유형 태그하기", "다음 유형 예고")
- **캡션 첫 줄**: "모두 필름이 펴낸 책이에요"
- **제약**: 판매 수치·stat 금지(린트 '큐레이션수치'), "100권"은 선정 기록이 있을 때만, MBTI를 과학적 진단처럼 다루지 않음. 16유형 → 4회차(`/series F02 --n 4`), 회차마다 훅 유형 교대 실험.
- **왜**: @feelmbook에서 이미 돌고 있는 현행 연재. 정체성 기반이라 태그·공유 → 비팔로워 도달. 백리스트 롱테일을 깨운다.

## F03 #한페이지필사
- **구조**: cover("이번 주 필사 문장" + 책 제목) → quote(승인 문장 80자 이내 + page) → text(따라 쓰기용: 문장 반복 + 넓은 행간) → text(필사 후 질문 하나) → cta("#한페이지필사로 인증해 주세요", "저장")
- **제약**: 같은 문장 반복 금지(quotes 사용 이력), 니체 엮음서의 대표 회복 서사는 grant(ceo_story) 없이는 금지, 경품=경제상 이익→레드, UGC 리포스트는 작성자 동의 기록 후(옐로)
- **왜**: 텍스트힙 → 라이팅힙(필사 도서 +64.7%, #필사 약 78만). 같은 요일 반복으로 습관·UGC.

## F04 3줄 인사이트 (번역서)
- **구조(캐러셀)**: cover(출판사 공식 소개의 저자 경력만 쓴 권위 훅, 예 "전 골드만삭스 CEO가 말하는 생존 지능") → list(핵심 원칙 3) → text ×3(원칙별 오늘 적용할 장면) → book(원제·역자 크레딧) → cta("저장해두고 월요일에 다시")
- **숏폼**: hook(의외의 질문) → caption ×3 → book → cta
- **대상**: 생존 지능, 어떻게 살아낼 것인가, 린치핀, 데일 카네기의 인간관계 수업, 오늘 일 재밌었어
- **제약**: 직접 인용·저자 사진은 `data/rights.json` 범위 안에서만(없으면 요약형·타이포만). 'NYT 베스트셀러' 등 해외 수치도 claims 등록 후에만.
- **왜**: 번역서는 국내 팬덤이 약해 출판사가 인지도를 만들어야 한다. 정보형 저장 포맷.

## F05 저자의 숫자, 당신의 체크리스트
- **구조(캐러셀)**: cover(질문 훅 또는 저자 사례 명시 "월 200 받던 간호사 부토리의 첫 1년" — 수익액 단독 훅 금지) → text("저자의 개인 사례이며 수익을 보장하지 않습니다") → list(실행 체크리스트 5, 일반 원칙) → text ×2(단계) → stat(등록분만) → book → cta(저장)
- **숏폼**: hook("종잣돈, 어디서부터?") → caption ×3 → book → cta
- **대상**: 부토리, 로또맘, 자본주의학교, 할미언니, 돈깨비
- **제약**: '27억'·'건물주'는 책 제목·저자 사례 문맥에서만(린트 경고 유지), 비트코인 책은 개념 설명형만, 종목 추천·가격 전망 금지.

## F06 크리에이터 저자 [광고] 콜라보
- **구조(숏폼)**: hook(저자의 대표 질문, manifest 등록 저자 제공 사진) → caption ×2 → quote(저자 승인 문장) → book → cta(handle "필름 출판사", sub "저자 채널에서 이어보기")
- **표기**: 유료·협찬이면 campaign.json `sponsored:true`(또는 `author_collab.paid`) → `disclosure:"광고"`(시작·끝 장면 배지), title 맨 앞 "[광고]", caption·description 첫 줄 "[광고] 필름출판사 × 저자명"
- **제약**: 구독자 수는 저자 합의 후(claims 등록), 저자 목소리 복제 TTS 금지, 발행 7일 이내 author-check, 이해관계가 애매하면 광고 표기 기본. `assets/author-kit.md`는 사람이 저자 측에 전달.
- **왜**: 크리에이터 저자층은 필름만의 자산. 투명한 [광고] 표기 자체가 2024년 이후 신뢰 회복 장치.

## F07 메이드인 필름 — 금요 비하인드
- **구조(숏폼)**: hook("이 표지가 나오기까지", 실사) → caption ×3(교정지·표지 시안·입고 현장 실사 + 짧은 자막) → book(이번 주 신간) → cta("다음 주 표지 투표는 댓글로", handle "필름 출판사")
- **제약**: 생성형 AI 이미지 금지, 직원 얼굴은 초상 동의서가 manifest에 있을 때만. 사람이 편집한 영상은 수동 경로(사람이 `out/shortform/short.mp4`·`cover.jpg`를 넣고 build:short 재실행 금지).
- **왜**: 민음사TV·흐름출판 '메이드인 출판사'로 검증된 팬덤 공식. 실사 비중이 유튜브 '비진정성(양산형)' 리스크를 상쇄.

## F08 카페 공명의 한 자리
- **구조**: cover(매장 실사 + "연남 공명 창가에서 읽은 문장") → quote(승인 문장) → text(공간과 책을 잇는 2줄) → book → cta("이번 주말 공명에서 펼쳐 보세요", "저장")
- **제약**: 음료 쿠폰·구매 결합 혜택은 도서정가제 경제상 이익(합산 15%) → 레드 + 리드·영업 검토 메모. @cafegm_ 교차 게시는 사람이 수동.

## F09 다시 읽히는 책 — 기념일·리커버·이정표
- **입력**: `npm run catalog` 60일 내 기념일 (예: 『그럼에도 불구하고』 9주년 10-25, 『프롬프트 텔링』 1주년 10-27, 『린치핀』 15주년판 2주년 11-13, 『헤맨 만큼 내 땅이다』 1주년 11-18, 『상처 없는 밤은 없다』 10주년 12-03 — 발행 주체 확인 전 '필름 10주년' 표기 금지)
- **구조**: cover("N년째 읽히는 문장") → stat(등록 수치+시점, 없으면 삭제) → text(책·리커버 이야기 — 허구·익명 독자 사연 금지) → quote → book(리커버 표지) → cta
- **제약**: 굿즈(행운의 말 책갈피·액막이 키링) 증정 조건과 함께 쓰면 레드 + 15% 검토. "무료로 드려요" 금지.

## F10 셀프 체크 테스트 캐러셀
- **구조**: cover("요즘 내 피로지수, 셀프 체크해 볼까요?" + "재미로 하는 셀프 체크") → list(체크 문항 5) → text ×3(0~1 / 2~3 / 4~5개 결과와 한 줄 처방) → book → cta("결과를 댓글로", "친구에게 테스트 보내기", "전체 테스트는 프로필 링크")
- **제약**: 진단·치료·완치·증상 개선 표현 금지. ppd.feelmgroup.com 링크 설정은 사람이.

## F11 신간 D-7 카운트다운
- **구조(캐러셀)**: cover(사실 기반 전작 연결 "『당신은 결국 무엇이든 해내는 사람』 김상현 작가 신작") → text(이 책이 답하는 질문) → quote(승인 문장이 있을 때만) → list(목차 하이라이트 3) → book → cta(예약판매·서점 링크 — 할인은 10% 이내 표현만)
- **숏폼 3편**: D-7·D-3·D-day, `/series F11 --n 3`. 회차마다 훅·이미지 변주(양산형 방지).

## F12 대표의 1분 — 작가 김상현 브리지 쇼츠 (레드)
- **구조(숏폼)**: hook(대표의 질문) → caption ×1~2(대표가 직접 쓴 문장 원문 — 에이전트 창작 금지) → book → cta("풀버전은 작가 김상현 채널에서", handle "필름 출판사")
- **제약**: 대표 사진은 manifest 동의 기록이 있을 때만, 대표 롱폼 클립은 동의 후 F07 수동 경로, 17억 빚·건강 서사는 grant(ceo_story) 필수, '작가 김상현' 표기(동명이인 방지), 대표 개인 계정에는 발행하지 않음. 대표가 publish 승인, 주 1건 상한.
- **왜**: 대표 채널 시청자를 휴면 상태인 회사 유튜브로 옮기는 다리. 얼굴 있는 출판사 서사.
