# 콘텐츠 검수 체크리스트 (필름 카드뉴스·숏폼)

> 기준일 2026-10-04. 자동 검수는 `npm run lint:copy -- <캠페인>`(결정론) → `compliance-reviewer` 에이전트(맥락 판단) → 사람 승인 순서로 진행합니다.

## G. AI 사용 표시
- **법적 지위**: AI 기본법(2026-01-22 시행) 제31조 표시 의무는 'AI사업자'의 의무입니다. 자사 채널에 AI로 만든 콘텐츠를 올리는 필름은 과기정통부 해설상 원칙적으로 **'이용자'**라 직접 의무 대상이 아닙니다. AI 생성물 표시를 의무화하는 정보통신망법 개정은 **2027년 6월 목표로 아직 시행 전**입니다.
- **그래도 표시하는 이유(사내 원칙)**: 2024년 지적 이후의 신뢰 회복, 유튜브 '변경·합성 콘텐츠' 공개 정책(사실적 합성물), Meta 'AI 정보' 라벨 정책, 향후 법 개정 대비.
- 규칙: AI 음성(TTS) 사용 시 설명·캡션에 "AI 음성으로 제작" 표기 + 영상 마지막 장면 자동 고지 / 사실적인 AI 이미지 사용 시 `ai_label: true` / 유튜브 업로드 시 `containsSyntheticMedia` 자동 설정.

| 항목 | 기준 |
|---|---|
| 인스타 캐러셀 | **API 자동 발행은 2~10장**(앱 수동 업로드는 20장), 4:5(1080×1350) 기본, JPEG |

| 유튜브 | 제목 100자, 설명 5,000자, 태그 합계 500자 / API 프로젝트 **감사 통과 전 업로드는 비공개 고정** |
| 대량 양산 주의 | 유튜브 2025-07 '비진정성 콘텐츠' 정책 — 같은 템플릿에 텍스트만 바꾼 영상을 대량 발행하지 않기(포맷·내용 변주) |

## I. 승인 게이트
1. **기획안 승인(plan)** — 마케팅 리드: 목표·타깃·포맷·핵심 메시지·사용할 수치/인용
2. **시안 승인(draft)** — 마케팅 리드: 렌더 결과(컨택트 시트·영상), 린트 오류 0
3. **최종 발행 승인(publish)** — 마케팅 리드 또는 대표: 캡션·해시태그·일정. 승인 순간 산출물 SHA-256 잠금 → 이후 수정 시 재승인
- 승인은 사람만 `npm run approve`로 기록합니다(에이전트 세션은 차단).
